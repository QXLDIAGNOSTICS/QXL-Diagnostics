# Cardiovascular and Pre-Disease Radar — clinical product specification
Stage 1: read-only education, no patient score. Stage 2: clinician-only prototype using synthetic/de-identified approved cases. Stage 3: release only after documented medical, privacy, security and regulatory assessment, independent clinical validation and sign-off.

Cardiovascular model: consider WHO 2019 South Asia lab-based charts, including India (https://www.who.int/news-room/detail/02-09-2019-who-updates-cardiovascular-risk-charts ; https://pubmed.ncbi.nlm.nih.gov/31488387/). Implement exact approved chart or published equations, no interpolation or extrapolation outside valid domain unless specified. Obtain permitted versioned model source, double-enter chart values independently, reconcile every cell, compare published cases and boundaries, document Indian population applicability and calibration limits. Do not implement US PREVENT as default Indian model without documented validation (https://professional.heart.org/en/guidelines-and-statements/about-prevent-calculator). The engine.py callback is intentionally disabled until the model adapter has been approved; this pack does not supply clinical coefficients or a risk percentage. Required input per model: age, sex variable as defined by model, smoking, diabetes, systolic BP, total cholesterol in expected units. Capture known CVD and acute symptoms before any score; refer out-of-domain or missing inputs to clinician. Do not treat risk estimate as diagnosis or prescription.

Independent biomarker layers: lipid profile (TC, HDL-C, LDL-C, TG, non-HDL-C), ApoB, Lp(a), hs-CRP, HbA1c, eGFR/uACR as indicated. Homocysteine and NT-proBNP only in clinically justified pathways, not default screening or added to model. Do not convert Lp(a) mass/molar values with a fixed factor. Store report assay, units, specimen, measured time, lab-specific reference interval, age/sex/pregnancy context, medications and limitations. Do not silently calculate LDL-C when method constraints are not met. No automatic test upselling or drug changes.

Radar pathways (each independently governed): cardiovascular, diabetes/metabolic, renal, liver, thyroid/endocrine, nutritional, inflammatory/autoimmune. Do not imply early cancer detection, population screening for autoimmune disease, or detection of all preclinical disease. Each module requires specific eligibility, indications, exclusions, critical-value policy, reference interval versus decision limit, source and version. No universal radar score or risk percentage. Initial outputs: incomplete data, clinical review required, threshold flag, comparable trend, non-comparable trend. Personal baseline is descriptive and not a substitute for validated decision limits. RCV only with medically verified CVa for the assay, CVi source, stability, distributions and confidence; source candidate https://biologicalvariation.eu/ ; use asymmetric approaches when indicated. Critical results remain in LIS-authorised escalation workflow; never rely on portal display.

Storage: patient/tenant ID; measurement ID; test ID; units (UCUM mapping); specimen; assay/platform; timestamp; authorisation ID; range and rule version; source URL; contextual eligibility; result status; reviewer ID; reviewed time; patient-facing text version; decision and follow-up; audit event. Use authenticated server-side access, least privilege, encryption, retention/deletion policy and consent where applicable. No identifiable results in public SEO, analytics, URLs, llms files or AI prompts. Clinician review must precede individual recommendations. Disable all public calculations by default. Model updates require a new version and regression tests; never silently rewrite historical decisions. Evaluate false positives, missed cases, subgroup performance and calibration before clinical release.

UI: public evidence pages with sources; optional clinician-only input form; strict unit selectors, missing data indicators, no prefilled patient values; separate absolute risk (if approved) from marker interpretation and longitudinal trend; show model/source/version, uncertainty, clinician review status. Emergency warning and escalation remain visible. Export only through access-controlled route. No automatic prescriptions or booking based on algorithm alone.
